# 🎰 MAO游戏 v2.0.0

一个功能完整的区块链游戏平台，支持多种代币、用户等级系统、邀请机制和智能合约集成。

## ✨ 主要功能

### 🎮 核心游戏功能
- **转盘游戏机制**：50%中奖率，最高100倍奖励
- **六级奖励系统**：特等奖(100x)、一等奖(20x)、二等奖(5x)、三等奖(2x)、四等奖(1.1x)、安慰奖(1.01x)
- **双代币支持**：MAO(100) 和 PI(1000)
- **实时动画效果**：转盘旋转、彩纸效果、胜利庆祝

### ⭐ 用户等级系统
- **青铜** (0次游戏): 0%加成
- **白银** (100次游戏): 5%加成
- **黄金** (500次游戏): 10%加成
- **铂金** (1000次游戏): 15%加成
- **钻石** (5000次游戏): 20%加成

### 🎁 社交功能
- **邀请系统**：生成专属邀请链接，好友使用可获得永久5%加成
- **全球排行榜**：实时显示前10名玩家及个人排名
- **社交分享**：支持分享到微信、QQ、微博

### 🔐 区块链集成
- **MetaMask钱包连接**：安全的钱包集成
- **代币余额查询**：实时显示MAO和PI代币余额
- **智能合约支持**：可配置合约地址进行链上交互
- **账户切换监听**：自动处理钱包账户和网络切换

### 💾 数据持久化
- **LocalStorage存储**：游戏数据、统计信息、历史记录自动保存
- **跨会话保持**：刷新页面数据不丢失
- **数据导出**：支持导出游戏数据为JSON文件

### 🎨 用户界面
- **现代化设计**：渐变背景、流畅动画、响应式布局
- **实时通知系统**：成功/错误/信息提示
- **详细统计面板**：游戏次数、中奖率、总盈亏、ROI等
- **游戏历史记录**：最近50条游戏记录

### ⚙️ 高级功能
- **设置面板**：音效、动画、统计、合约地址配置
- **帮助文档**：完整的游戏规则和使用说明
- **键盘快捷键**：快速操作支持
- **防作弊机制**：随机数种子验证
- **自动连接**：记住钱包连接状态

## 🚀 快速开始

### 1. 打开游戏
直接在浏览器中打开 `game-production.html` 文件

### 2. 连接钱包
- 点击"连接钱包"按钮
- 确保已安装MetaMask浏览器插件
- 授权连接

### 3. 开始游戏
- 选择代币类型（MAO 或 PI）
- 点击"开始游戏"按钮
- 等待转盘结果

### 4. 邀请好友
- 点击"生成邀请码"
- 复制邀请链接分享给好友
- 好友使用链接进入可获得永久5%加成

## ⌨️ 键盘快捷键

- **空格键**：开始游戏
- **1**：选择MAO代币
- **2**：选择PI代币
- **Shift + H**：打开帮助
- **Shift + S**：打开设置
- **ESC**：关闭模态框

## 🔧 智能合约配置

如需集成真实的区块链合约，请在设置面板中配置：

1. 打开设置 (Shift + S)
2. 输入MAO代币合约地址
3. 输入PI代币合约地址
4. 输入游戏合约地址（如果有）

当前版本使用模拟模式，所有交易在本地进行。

## 📊 游戏统计

点击右下角的📊按钮可查看详细统计：
- 基础统计（总次数、中奖率、总盈亏）

- 排名信息（全球排名）

// 导出游戏数据
